# Card Payments by Merchant Category

## Project Overview
A Data Science and Machine Learning project analysing card payment transactions across different merchant categories.

## Dataset
- 284,063 records
- 362 merchant categories
- Payment values and transaction counts

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## Project Objectives
- Data cleaning and preprocessing
- Exploratory Data Analysis
- Data visualisation
- Machine Learning analysis
